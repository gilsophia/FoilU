# FoilU/电电你的（Photoshop CEP 插件）

一键把所选图层模拟成电化铝烫色效果：按画布毫米尺寸与 DPI 自动标定 6cm×6cm 烫材贴图的拼贴比例，带 0.3mm 凹陷压痕、微反光、珠光（默认 80% 不透明度）与透明烫材（保留贴图 alpha 透明区、默认 65% 纹理不透明度）效果；支持多图层批量导出（自动识别模切 / 烫色 / 印刷，并按图层名匹配烫材与优先级，生成结果自动编组收起）、刀线裁切（联动印刷层模切）、厂家/色彩筛选、星标收藏、正则搜索与自定义烫材。

当前版本：v1.2.1（内置烫材 1487 款，已按「厂家-型号色彩」命名；6cm×6cm 标定；多图层导出、自动匹配与优先级、每次生成自动编组收起并隐藏旧组、珠光 80% / 透明 65%）

## 安装

1. 右键 `install/install.ps1` → 使用 PowerShell 运行（无需管理员）。
   脚本会做两件事：
   - 在 `%APPDATA%\Adobe\CEP\extensions\com.foilu.panel` 创建指向本插件目录的目录联接（Junction）；
   - 写入 `HKCU\Software\Adobe\CSXS.8 ~ CSXS.12` 的 `PlayerDebugMode = 1`（CEP 未签名扩展必需）。
2. 重启 Photoshop。
3. 打开面板：`窗口` → `扩展功能（旧版）` → `FoilU 电电你的`。

卸载：运行 `install/uninstall.ps1`（或发布包中的安装程序，可在 Windows「设置 → 应用」中卸载）。卸载/更新不会删除自定义材质（`%APPDATA%\FoilU`）与星标收藏。

### 发布包结构（本体 + 扩充包）

- **基础包**（`FoilU_电电你的_基础包_Setup.exe`，约 45MB）：**插件本体 + 最初内置的 33 款烫材**。只需安装一次；**更新代码时只装基础包即可**——已有材质库会保留（同名内置材质自动更新为最新版），不会影响扩充包与自定义材质。安装器同目录若有扩充包安装程序，可在安装界面**直接勾选**（默认全选）随基础包一并安装；安装完成后同目录会释放《FoilU_电电你的_效果演示v1.2.1.psd》。
- **扩充包**（按厂商拆分，先装基础包再逐个安装，顺序随意）：
  晨辉 415 款 / 金合彩 440 款 / 金穗 263 款 / 臻彩 102 款 / 殷帆 90 款 / 升盛 60 款 / 恒昌 37 款 / 库尔兹 34 款 / 皇泰烫金 3 款 / 卓鑫 3 款 / 其他 3 款 / 辉煌 2 款 / 鑫昌泰 2 款。
  扩充包**只把对应厂商的烫材与缩略图加入插件**（同名材质会被更新），不会改动插件代码、其它厂商材质或自定义材质。
- **材质迭代**：若某个厂商的材质有更新，重新安装该厂商的扩充包即可。
- **免安装版（备用安装方式）**：Windows 11「智能应用控制」会拦截未签名的安装程序（.exe，且没有“仍要运行”选项）。安装器被拦截时可改用与安装包一一对应的「**免安装版**」ZIP（形如 `FoilU_电电你的_*_免安装版.zip`）：解压后双击其中的「**一键安装.bat**」即可（扩充包会先检查基础包已安装；基础包会自动开启 PlayerDebugMode）；若 bat 也被拦截，按 ZIP 内《安装说明.txt》手动把 `materials`、`thumbs` 文件夹拖入 `%APPDATA%\Adobe\CEP\extensions\com.foilu.panel`。基础包 ZIP 会自动检测同目录的扩充包 zip，可在命令行按编号一并解压安装（all = 全部）；ZIP 内附效果演示 PSD。免安装版内容与对应安装包一致，不含 exe、不会被系统拦截。
- 卸载：用「基础包」的卸载入口（整体移除插件；自定义材质与星标保留）。

> 支持 Photoshop CC 2019 及以上（CEP 9+，含 Photoshop 2020），Windows 系统。

## 使用

1. 打开文档，选中要烫色的图层（文字 / 图形 / 位图均可）。插件忽略图层原本的颜色、透明度与 alpha 值，只按“有内容”的范围烫印。
2. 烫材由「文档图层」列表**自动匹配或手动指定**；点「刷新」后预览跟随当前图层的匹配烫材显示（珠光 / 透明按材质名**自动启用**，主页卡片实时显示当前不透明度，无需手动勾选）：
   - **珠光**：默认 80% 不透明度（「珠光白」按比例约 47%），颜色默认白色，可在左侧「珠光色」子界面用 RGB 色轮自选；不透明度可在「效果参数 → 珠光不透明度」用滑杆调整（「珠光白」随滑杆等比换算），旁有「重置」恢复默认；
   - **透明**：贴图 alpha 透明区不覆盖原稿颜色（默认 65% 纹理不透明度），保留反光；纹理不透明度可在「效果参数 → 透明不透明度」用滑杆调整并重置。
3. 点击「一键生成烫色图层」，在所选图层上方生成写实烫色层（可再自行调透明度 / 混合模式）。

### 多图层导出（主页图层列表）

点「刷新」后主页会列出文档全部图层（只显示名字，可逐层分配用途）：

1. **自动匹配**：打开文件后首次刷新即按图层名自动识别（含「模切/刀线」→ 模切；含「印刷/柄图」→ 印刷；含「烫」或名字能明确匹配到烫材（如「透明红」→「臻彩-817透明红」）→ 烫色，并模糊匹配烫材名；优先按名称与型号匹配，缺少原型号时按近似花纹与颜色选材；插件生成的图层自动排除）；烫色层**优先级自动按图层上下顺序分配**（最上面 = 优8，越往下越小；越往上导出后越靠上，可手动调整）；改完图层后可点标题右侧「**自动匹配**」重跑；
2. **烫材备选池**：到「烫材库」把要用的烫材点卡片左下角 **＋** 加入备选池（备选池非必选，空池依然可以生成；手动指定优先；每层「重置」解除手动指定）；
3. **刀线核对**：到「刀线裁切」确认识别模式（自动 / 描边 / 填充）与识别结果（主页引导卡实时显示状态）；
4. **图层分配**：可手动改每个图层为 模切 / 烫色 / 印刷 / 忽略；烫色层可设**优先级 1-8**（数字越大，导出后越靠上）与各自烫材；
5. **导出**：每个烫色层单独渲染、按优先级叠放、印刷层永远在所有烫色层下方；生成结果装入一个以生成时间命名的**新组**（位于所有组与图层之上、自动收起），旧生成组自动隐藏且不再被覆盖检索；
6. **导出完成后**，被分配的原始图层自动**隐藏（内容不改动）**；生成组及组内图层在列表中默认识别为「忽略」。

### 刀线裁切

- 「刀线」子界面开启后，实际裁切对象是**主页图层列表中设为「模切」的图层**（在主页改动角色会实时重新识别）；刷新 / 自动匹配时，图层名匹配正则的图层（默认 `模切|刀线`，可自行修改）会被自动分配为「模切」；插件自己生成的图层会自动排除，不会被误当成刀线；
- 自动识别图层内容类型（支持任意颜色）：闭合线条 → 取「轮廓圈住」的区域，支持多层嵌套——轮廓内再被圈住的镂空会自动挖空，开放线条不会误判，轮廓超出画布被裁切也能正确闭合成区域；实心填色 → 取「填色区域」。识别模式可手动指定（自动 / 描边 / 填充）；
- 生成时会自动读取名称含「**印刷**」或「**柄图**」的图层，按同一刀线生成模切印刷层（无需选中它），印刷层永远位于烫色层下方；
- 重复生成时：印刷层模切覆盖上一次；同烫材的烫色层被覆盖、不同烫材各自保留——且只覆盖插件自己生成的图层。

### 生成图层命名

生成的图层名为 `日期-时间-烫材名`，例如 `261006-020840-臻彩-1202银玻璃碎`（YYMMDD-HHMMSS-材质名）；印刷层模切为 `日期-时间-印刷(模切)`。每次生成还会创建一个**同格式（如 `261008-154728`）的新组**，位于最上方、自动收起；旧生成组自动隐藏，不再被覆盖检索，也**不会误删你手动命名的图层**。

### 烫材默认尺寸

- 贴图统一按实体 **6cm×6cm**（1000×1000px）标定，默认缩放即 6cm；
- 切换烫材时自动应用「该烫材的缩放」：优先你上次为它设置过的比例（自动记忆），没有记录则用默认值；「效果参数 → 烫材缩放」旁的「**重置**」按钮可清除记忆、恢复默认；
- 个别未更新到 6cm 的旧贴图（橘皮、万花筒、爱心等 13 款）仍保留 15cm（150mm）默认。

### 预览

- 预览左上角三个缩放按钮：适应 / 100% / 200%，高倍率下可看清凹陷与反光细节；
- 预览会跟随 Photoshop 的「旋转视图」角度（如你的 PS 版本支持读取）；也可用预览上的 ↺ / ↻ 按钮手动校正 90°，旋转后自动适应窗口；
- 参数、烫材、勾选项变化会实时重渲染预览；预览的烫材跟随「文档图层」列表里当前图层的匹配结果（修改该层烫材或重新随机 / 自动匹配后会同步更新）；
- 图层或文档变化后按「刷新」重新读取；
- **面板缩放**：按住 **Ctrl + 鼠标滚轮** 缩放整个面板界面（0.5×–5×，默认 2.5×），自动记忆。

## 材质规则

- 贴图物理尺寸统一约定为 **6cm×6cm**（1000×1000px），插件按画布 mm 尺寸 × DPI 自动换算拼贴缩放；「效果参数 → 烫材缩放」可手动调整（显示当前实体尺寸），每款烫材的缩放会被记忆。
- 命名规则：`厂家-型号色彩`，例如 `臻彩-1202银玻璃碎`、`金穗-J7214墨绿`、`殷帆-11黑`、`库尔兹-白星`；无厂家信息的贴图保持原名。库内所有材质均以该格式呈现，分类时名称开头的厂家品牌词不计入颜色判定。
- 贴图文件名含「**珠光**」→ 自动启用珠光（默认 80% 不透明度）；含「**透明**」→ 自动启用透明（默认 65% 纹理不透明度、保留透明区）。自定义材质入库时可勾选「珠光 / 透明」属性（不依赖名称）；主页卡片实时显示当前不透明度，不透明度可在「效果参数」用滑杆调整（「珠光白」随珠光滑杆等比换算，默认约 47%）并一键重置。
- 「**冰川蓝**」等自带半透明通道的贴图会自动按**原始 alpha** 呈现（透明处透出底稿、不按透明不透明度压暗），不会被渲染成实色。
- 烫材库支持厂家 + 色彩组合筛选、名字搜索（支持正则，无效正则自动按普通模糊匹配）与星标收藏；星标存于 `%APPDATA%\FoilU\stars.json`，随插件更新保留；贴图丢失时显示占位警示，可「重新挂载」或「删除」。
- 内置材质随插件目录封包（`materials/`），更新插件即可整体替换；素材源文件夹为 `电化铝材质贴图/`，厂家对照见 `素材重命名映射.csv`。
- 贴图支持 **PNG / JPG / WebP**；内置材质已压缩为 WebP（优先无损、压不动的用近无损 q95），体积约减少三分之一，画质与原图无可见差别；替换前的原图备份于 `电化铝材质贴图/PNG原图备份/`。

### 自定义烫材

- 支持常见图片格式（**PNG / JPEG / WebP / BMP / GIF** 等，任意尺寸），也支持**实拍样卡照片**；
- 选择图片后进入**处理预览**，确认前可调整：
  - **旋转**：「左转 90° / 右转 90° / 180°」手动校正，或点「自动文字方向」——插件会尝试 0°/90°/180°/270° 四个方向做离线 OCR（调用 Windows 自带 OCR，无需联网），按识别文字最多的方向自动摆正；
  - **自动裁切色卡**：自动识别照片中的色卡区域（以照片四边为背景参考），去白边，取色卡内最大内切方形，避免把纸张背景带进纹理；
  - **去除圆环压痕**：自动检测样卡上的金属圆环（亮带 RANSAC 圆拟合＋方向一致性校验），沿圆环区域用同色卡干净区域做羽化修补；
  - **自动命名**：用识别到的文字（如 `L2-057银回字格`）自动填入材质名称，可手动修改；
  - **珠光 / 透明属性**：可勾选入库为「珠光」「透明」材质（按名称自动预勾选）；入库后该材质自动按对应不透明度效果使用，名称无需包含关键词；
- 确认后按「处理方式」生成 1000×1000px 并入库：
  - **接缝融合**（默认）：半幅偏移 + **最小误差切割线**拼接（动态规划沿色彩最接近的路径裁切），基本消除拼接线与重影；「切割搜索宽度」可调 8%–30%。若原图边缘本身已接近连续，则只做缩放不融合；含透明通道的贴图会先询问；
  - **镜像平铺**：不做融合，渲染时以镜像方式平铺，数学上零拼接线（列表中标有「镜像」角标）；
- 不勾选自动处理时，建议自行上传 1000×1000px 四方连续贴图；尺寸不符会提示确认；
- **双击自定义材质名称可重命名**（重命名即改文件，选中状态下会同步更新）；
- 自定义材质单独存放于 `%APPDATA%\FoilU\custom`，与封包的内置库分区，重装 / 升级插件不会丢失。

## 技术说明

- CEP 面板 + WebGL 渲染（渲染精度上限约 30MP 蒙版 / 48MP 输出，超出自动降采样后由 Photoshop 拉伸回原尺寸）；
- 通过 ExtendScript 复制文档导出所选图层蒙版与整图预览（临时副本自动隐藏以减少闪烁）；结果 PNG 用「置入」命令写回为图层（不打开新文档；如你的 PS 不支持自动回退为复制粘贴方式）；
- 若生成时提示无法通信，请确认 Photoshop 中已打开文档且未处于模态对话框状态。

### 自动与随机选材

- 烫材池为空时可以生成，未手动指定的烫色层按名称、型号模糊、近似花纹与颜色依次匹配全库。花纹和颜色依据材质名称与现有分类标签判断。无法识别时使用默认材质并显示“默认”，可以手动更换。
- 手动指定的烫材优先于名称匹配；再次刷新和自动匹配会保留。每层“重置”清空该层选择及优先级，恢复自动选材。手动指定的文件丢失时提示重新选择，不擅自换材。
- 主页显示“想不出做什么烫材的话，就来试试随机吧！”，支持厂家与色彩组合筛选。随机分配给未手动指定的烫色层；再次点击可重新随机。无符合条件的材质时保留现有选择。

### 自定义色卡样本校准

上传整页色卡后，可在原图拖动框选单个色号，或选择没有压痕的纯纹理区域；旋转会清除框选。处理预览与保存使用同一结果。实拍样本校准可关闭，只有识别到色卡或手动框选时才启用，透明、多色及超出样本范围的素材保留原色。

本地颜色校准由 9 张金穗色卡照片、60 个色号的 180 组配对样本拟合。使用 108 组训练、54 组不同拍摄角度验证，18 组彩虹样本不参与单色校准。验证集对生成参考图的中位 RGB 误差降低约 38.3%，仅表示该样本集的色彩接近程度，不代表实物色度精度或训练了图像生成大模型。纹理细节仍来自上传原图。

若材质名称包含明确色号且库内仅有一个对应素材，可复用该成品纹理；界面会显示来源，可关闭此选项。它是参考素材复用，不是凭照片重新生成。照片过曝、失焦或只拍到局部彩虹时，单靠颜色校准无法恢复缺失的纹理和完整色谱，建议框选清晰区域或使用已匹配的库内纹理。

### 圆环压痕修补

去环在裁切前拟合倾斜的椭圆，并通过弧线连贯性验证。只有确认的圆环区域才会进入修补；正常颗粒、阴影和多边形边界不再按深色连通区域修补。颗粒材质使用完好区域的细节补纹理，深色多边形材质使用窄带修补，减少花纹拉花。缺失的真实图案仍可能在修补区域轻微软化。
